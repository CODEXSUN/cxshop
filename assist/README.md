# CXShop Assist

Assist contains the active product, architecture, governance, and delivery instructions for CXShop.

## Document map

- `AGENT-GUIDE.md` routes all repository work.
- `product/ecosystem.md` defines the product and portal ecosystem.
- `product/delivery-roadmap.md` defines delivery stages and completion gates.
- `architecture/bounded-contexts.md` defines domain ownership.
- `architecture/marketplace-model.md` defines core marketplace behavior.
- `architecture/integration-contracts.md` defines CXApp and Frappe integration.
- `architecture/events-and-queues.md` defines reliable asynchronous work.
- `architecture/security-and-tenancy.md` defines trusted scope and access rules.
- `architecture/runtime-and-portals.md` defines the runnable workspace, portal routes, and module standard.
- `architecture/frontend-and-api-stack.md` defines SSR, routing, API documentation, queues, UI libraries, and testing.
- `governance/rules.md` defines mandatory engineering rules.
- `governance/dependencies.md` defines the owned-code and dependency approval boundary.
- `governance/quality-gates.md` defines required verification.
- `operations/deployment.md` defines the guarded container workflow.
- `operations/shared-infrastructure.md` defines external CXApp resource reuse.
- `operations/versioning.md` defines releases and `github:now`.
- `documentation/project-inventory.md` records the current implementation state.
- `skills/cxshop-module-owner/SKILL.md` gives agents an implementation workflow.
